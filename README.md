# NEXORA TECH — Technology Store

**Technology meets design. Una experiencia de e-commerce conceptual enfocada en diseño, funcionalidad y experiencia de usuario.**

[🌐 Ver demostración](https://myrem-droid.github.io/nexora-tech/)

---

## ✦ Descripción

NEXORA TECH es un proyecto de e-commerce ficticio desarrollado para demostrar la creación de una tienda tecnológica moderna.

Su identidad visual combina superficies oscuras, detalles naranjas y una estética editorial inspirada en marcas tecnológicas premium.

## ✦ Características

- Diseño responsive para escritorio, tablets y móviles.
- Catálogo con 12 productos de demostración.
- Búsqueda de productos.
- Filtros por categoría.
- Ordenamiento por precio y nombre.
- Ventanas de detalles de productos.
- Carrito de compras interactivo.
- Control de cantidades.
- Sistema de favoritos.
- Persistencia de carrito y favoritos mediante LocalStorage.
- Proceso de compra simulado.
- Formulario de newsletter demostrativo.
- Notificaciones interactivas.
- Animaciones y transiciones.
